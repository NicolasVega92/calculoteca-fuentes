# Calculoteca: cuentas y fuentes

Cada video del canal prueba una idea con números propios. Acá están las cuentas y las fuentes de cada uno, para
que cualquiera pueda rehacerlas.

Cada carpeta tiene:

- `cuentas.py`: todas las cuentas del video. Solo usa la biblioteca estándar de Python 3.
- `cuentas.json` y los CSV que escribe: el resultado, tal como se usó en el video.
- Los datos descargados, con la fecha de descarga en el nombre cuando cambian con el tiempo.
- `fuentes.md`: de dónde sale cada dato y cada afirmación.

Para rehacer las cuentas: entrar en la carpeta del video y correr `python cuentas.py`.

| Carpeta | Video |
|---|---|
| [`crisis-1929`](crisis-1929/) | La crisis de 1929 |
| [`loteria`](loteria/) | ¿Ganar la lotería te arruina? |

Contenido educativo general, no consejo financiero personal. Los datos son de sus fuentes, citadas en cada
`fuentes.md`. Si encontrás un error, abrí un issue.
